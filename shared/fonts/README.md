# Fonts

Bungee, Bungee Shade, Rubik, Silkscreen, Russo One, Chakra Petch and VT323, downloaded from Google Fonts (the latin
sets only) and served from here, so pages don't wait on another server and the installed app has them offline.
`shared/fonts.css` declares them. Each is under the SIL Open Font License 1.1; the licences and copyright notices are
in `OFL.txt`.
