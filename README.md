# Bitcade

Ten classic-style arcade games that run in your browser, on phone or keyboard.

**Play:** https://gfrazier620-afk.github.io/Bitcade/

| Game | Style |
|---|---|
| Neon Noodle | Snake |
| Wallbuster | Brick breaker |
| Star Siege | Alien shooter |
| Rock Rift | Asteroid blaster |
| Stackdown | Falling blocks |
| Back Alley Brawl | Street fighter |
| Circuit Chase | Maze chase |
| Highrise Handyman | Fix-it climber |
| Nitro Lane | Racing |
| Blip Sports | LED football + baseball |

Top-10 score tables with your initials save in your browser. Stackdown and Wallbuster have a daily challenge that gives every player the same pieces or walls. To run it locally, use `python3 -m http.server` in this folder, then open http://localhost:8000.
